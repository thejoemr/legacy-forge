# Catálogo de conceptos

Lista base de conceptos a buscar en M4. Omite los que no existan en el
codebase. Agrega conceptos propios del proyecto si encuentras un tipo de
pieza recurrente que no está aquí.

## Entrada

- Puntos de entrada y arranque: Program, Main, Startup, bootstrap.
- Endpoints y controladores: API REST, SOAP, GraphQL, gRPC.
- Pantallas y vistas: páginas, componentes de UI, formularios, plantillas.
- Navegación y rutas de UI.
- Jobs y tareas programadas.
- Consumidores de eventos y colas.

## Lógica

- Reglas de negocio y casos de uso.
- Validaciones.
- Cálculos y procesos de dominio.
- Entidades y modelos de dominio.
- Enumeraciones y constantes de negocio.

## Datos

- Acceso a datos: repositorios, DAOs, consultas SQL, stored procedures.
- Modelos de persistencia y mapeos ORM.
- Migraciones y scripts de base de datos.
- DTOs y objetos de transferencia.
- Mapeos entre modelos (mappers, AutoMapper, conversores).
- Cache.

## Integración

- Clientes de APIs externas.
- Productores de eventos y colas.
- Lectura y escritura de archivos.
- Envío de correo y notificaciones.

## Transversal

- Configuración y opciones.
- Inyección de dependencias y registro de servicios.
- Autenticación y autorización.
- Manejo de errores y excepciones.
- Logging, trazas y métricas.
- Middleware, filtros e interceptores.
- Utilidades y helpers compartidos.
- Internacionalización y textos.
- Recursos estáticos: imágenes, estilos, scripts de cliente.

## Calidad

- Tests unitarios.
- Tests de integración y end-to-end.
- Datos de prueba, fixtures y mocks.

## Entrega

- Build y empaquetado.
- CI/CD.
- Infraestructura como código y contenedores.
- Scripts de operación y mantenimiento.
